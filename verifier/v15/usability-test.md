# BioMapOS 研究员试用与测量方案

状态：尚未开展外部参与者测试。自动测试和代理浏览器走查不计入以下指标。

## 参与者与材料

邀请 5–8 名日常执行实验的研究员/实验员，另请 2 名方法维护/复核人员。先确定一个客户真实高频 SOP、批准设备、脱敏样本批次、物料单位、质控标准和输出文件。现有 qPCR 数据仅供软件 QA，不代表方法验证。

每位参与者使用独立测试账号和隔离数据。按客户当前稳定版与改版交叉排序，执行同等难度任务；不要让主持人预先演示操作路径。记录用户原话和阻碍，避免将主持人提示后的完成算作独立完成。

## 任务脚本

| 任务 | 给用户的目标 | 观察重点 |
| --- | --- | --- |
| T1 准备批次 | 按给定方法处理指定样本，保存可开始的计划 | 是否找到方法；是否误改固定参数；导入顺序和身份是否正确 |
| T2 修复缺项 | 物料不足或设备不可用，找到下一步 | 能否理解原因、定位缺项、联系正确负责人；不能用任意设备绕过 |
| T3 中断与交接 | 准备一半离开，再恢复并交接 | 字段完整性、谁有权限继续、旧负责人是否仍能覆盖 |
| T4 开始及执行 | 领取已核对物料，完成当前步骤 | 是否误认保存计划就是物理启动；证据是否对应当前步骤 |
| T5 异常与重做 | 一份样本缺结果或异常，处理后提交 | 是否理解暂停不等于停机；是否知道部分样本重做是新任务 |
| T6 结果复核 | 找到指定样本原始文件、方法版本和 ELN | 可追溯性、独立复核、签署后不可改的理解 |
| T7 方法维护 | 更改一个允许参数并提交新版本 | 工作副本与发布版本区分、差异阅读、历史任务不漂移 |

T4 不驱动真实设备。真实现场试用另按实验室的设备验证和人员安排执行。

## 衡量方法和建议目标

| 指标 | 建议门槛 | 当前测量 |
| --- | --- | --- |
| 标准任务独立完成率 | 形成性试用先争取 ≥80% | 未测 |
| 准备时间 | 较同任务基线减少 ≥50%，另记外部等待 | 未测 |
| 关键状态误判 | 演练/计划/运行/结果批准之间 0 次关键误判 | 未测 |
| 草稿恢复 | 所测字段全部恢复且无错人覆盖 | 工程验收通过；参与者待测 |
| 追溯成功率 | 所测结果都能定位样本、步骤、版本、原始文件 | 工程验收通过；参与者待测 |
| 模块切换与重复录入 | 记录次数，比较基线 | 未测 |

小样本用于发现问题，不据此声称统计显著性或全体客户满意度。
