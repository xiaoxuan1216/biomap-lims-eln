# BioMapOS 研究员任务工作区改版

依据：`交付成果/BioMapOS_产品审查_20260917.md`。主用户为日常执行实验的研究员/实验员。保留已有 BioView 工作区改动，保留历史 Run、节点身份、库存事务、ELN 签署和开放 API 门禁。

## 验收清单

- [x] A1 方法视图不显示执行进度，方法/计划/演练/实际执行用语准确。
- [x] A2 设备候选与后端启动检查使用同一能力约束；未知、不适配设备禁止错误就绪。
- [x] A3 默认执行工作区展示下一步动作、负责人和阻塞；取消为次级动作。
- [x] A4 日常导航收敛，专业功能仍可按职责进入；技术配置渐进展开。
- [x] B1 我的工作提供本人任务、草稿、待处理和记录入口。
- [x] B2 任务准备可保存恢复、换人交接；批量样本导入和明确映射；仅所需方法要求布局。
- [x] B3 已发布方法输入约束、固定参数和可调范围；材料需求与缺项修复。
- [x] B4 真实人工执行及设备人工采集具有操作者、时间、证据；不伪造设备回执。
- [x] B5 结果绑定任务/步骤/样本/方法版本/原始文件，结果复核与技术完成分离。
- [x] B6 任务自动生成 ELN 草稿并链接签署流程；保留自由记录。
- [x] C1 方法版本复核发布、停用、差异；历史快照冻结；旧方法不自动发布。
- [x] C2 子流程编译与来源映射；分支、等待和跳过语义一致。
- [x] C3 暂停、交接、异常对账、部分重做与设备替代受控且可追溯。
- [x] C4 跨平台能力与上下文助手；演示数据和专业模块按工作区呈现。
- [x] V1 有意义的契约与集成测试、全量 lint/test/build、生产依赖审计。
- [x] V2 迁移审查、数据库备份、独立库验证、本地启动及中英文 UI 验证。
- [x] V3 外部用户可用性验证方案与测量记录；未经参与者测试不宣称达成效率指标。

## 变更边界与当前状态

开始前已有 BioView 相关未提交修改。原始跟踪文件差异保存在 `/private/tmp/biomap-before-product-redesign.patch`，未跟踪文件仍在原处，禁止清理或回滚。

当前本地服务运行在 Docker `biomap-v10-app`，MySQL 为 `biomap-preview-mysql`。修改与测试以源码为准；迁移应用和服务重启前先验证并备份。没有真实仪器接入的自动模式继续明确标为不可启动，不用 UI 模拟代替设备执行。

外部参与者测试依赖实际实验员及方法负责人，工程验证可先独立完成。工程清单已完成，证据见 acceptance.md。V3 完成的是试用方案与空白记录表；真实参与者测量仍待开展，不宣称产品效率指标达成。
