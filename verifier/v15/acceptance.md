## 已实现并验证

| 范围 | 行为与证据 |
| --- | --- |
| 方法治理 | 工作副本与发布快照分离；复核发布/停用、版本差异；旧流程保持待确认，不自动发布；图保存保持节点 ID；并发图修改检测 |
| 方法执行约束 | 明确输入、输出、完成标准、批准设备及依据；固定参数不可覆盖；可调参数范围；按批/样本计量材料需求 |
| 批次准备 | 三步准备、服务端草稿、刷新恢复、交接和冲突拒绝；批量完整 Sample ID、输入顺序映射、所需方法才要求孔板布局 |
| 领用与执行 | 任务页逐项核对领取；调用原有领用事务，不直接改库存；领用未完成不能启动；人工步骤、分支、等待、原始文件、操作者和时间 |
| 结果与记录 | 技术完成不自动批准结果；逐样本/步骤关联原始文件；更正追加历史；生成可读 ELN 并保留自由记录；独立复核、版本检查、永久签署 |
| 签署一致性 | 关联 ELN 禁止走独立签署接口；前端引导回任务；结果批准与 ELN 签署在同一事务完成 |
| 异常处理 | 暂停、现场对账后恢复、交接；批准设备范围内的替换申请与独立复核；选定样本建立新任务按完整方法重做，保留父任务与签署 |
| 子方法与演练 | 子方法展开并冻结来源；显式分支判断和跳过传播；演练等待需显式快进；演练不扣库存、不伪造结果 |
| 工作区与助手 | 本人任务/草稿/复核队列；日常与演练分开；上下文助手提供基于后端状态的只读建议；页面切换同步上下文；演示标记和可配置专业导航 |
| 历史正确性 | 后续方法修改、样本改名和批准设备偏差不会重写原计划；结果、签署与证据保留历史身份 |

## 边界与未达成事项

1. 当前实现真实人工操作的证据链；没有真实 Edge 设备接入、自动下发和现场设备验收，自动模式仍受门禁约束。
2. 选样重做是新计划按完整方法重做，不是任意中间步骤恢复。
3. 原始文件目前最多 2 MB，适用于本轮证据闭环；大文件/对象存储与多文件解析不属于已验收能力。
4. 专业导航配置是展示控制，不代表新租户隔离或新的细粒度权限系统。
5. 领用扣减与真实剩余量/损耗不是同一概念；额外消耗仍需单独记录。
6. 方法执行要求维护尚未做与图草稿相同的自动恢复；请显式保存执行要求后切页。图草稿保存在本机，批次准备草稿保存在服务端。
7. 客户真实 SOP、设备验证证据和参与者尚未提供，不能宣称独立完成率 ≥80%、准备时间降低 ≥50% 或“无需工程师代操作”已达成。测试方案与空白测量表见 `usability-test.md`。

后续退出标准是实际参与者完成上述任务并关闭关键误判/阻断问题。工程 QA 完成不替代这一产品验收。
