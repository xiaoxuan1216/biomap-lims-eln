# V24 BioView 收敛为 BioMap OS 原生实验视图

日期：2026-09-20。状态：工程实现与隔离 QA 库界面走查通过；未发布到外部环境，不代表真实设备连机或物理实验验收。

## 产品边界

- 不新增 `/bioview` 路由、侧边栏产品、API Router 或业务表。
- 方法编辑仍在 `/workflows/:id/edit`，“实验呈现”与流程图、孔板与样本属于同一编辑器。
- 实验发起仍在 `/runs/new`，实验视图读取已发布方法版本，并与本次样本、物料、孔板、设备及参数绑定。
- 运行态仍在 `/runs/:id`，实验视图使用冻结 RunPlan，再只读投影 LIMS 的实时证据链；不建立第二份样本、结果或文件数据。

## 本轮收敛

- 方法库、方法详情、我的工作和实验任务列表不再显示平行的“配置/查看 BioView”操作。
- 默认展示自动生成的实验视图；领域包、Renderer 和语义覆盖收入“高级呈现规则”。
- 实验发起阶段使用 `draft` 视图语义，明确显示“本次实验计划预览”；不再与方法模板预览混淆。
- 准备阶段不再维护独立 `RunPlanDataFlowPreview`，改为复用同一 `BioViewRuntime`；通用流程与分子克隆流程使用同一入口。
- Run 详情只保留“实验视图 / 执行详情”；原 `?tab=data-flow` 深链接兼容到实验视图，权威数据流不再重复呈现。
- 方法库发起 Run 时显式传入 `methodReleaseId`；Run 顶部回链冻结的来源方法版本。
- 对照样本与实验样本同属 sample-like 资源，不再被计入物料；同一 Blueprint 禁止重复 `rendererRef`。
- 孔板快照哈希收入折叠的审计摘要，不再占用默认操作视图。
- `public/share` 中的单文件 HTML 保留为历史视觉原型，README 已明确其不是产品入口。
