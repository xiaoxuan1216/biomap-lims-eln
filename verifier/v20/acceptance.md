# V20 执行记录中的批次信息沿用

方法字段可指定前序步骤的文字字段或本批冻结身份作为参考来源。方法发布检查引用的步骤关系与字段类型；新建克隆、表达、纯化草稿包含适用的批次引用。已有发布版本保持原状。

执行时按当前条目关联样本匹配已完成记录，展示来源和值，再由实验员填入空白字段。已有填写不覆盖；多个批次、未完成记录、样本对应不明确时不给出填充值。实测量、时间、检测数值不能配置为沿用字段。旧系统产物身份中的样本编号不作为真实批号填入。

检查：30 文件 / 271 测试、类型与构建通过；i18n 缺项和重复键为空，生产依赖审计零漏洞。QA 方法 72 / 发布版本 44，Run 65：中英 UI 从细胞状态步骤沿用培养批次，并从冻结来样身份填入 HC/LC 批号，保存为转染步骤草稿；用量、时间和测定值保持空白。`reuse-readback.mts` 验证服务端保存值和旧、新计划完整性。

这是软件功能示例，所有输入为合成 QA 数据，不代表现场实验。该示例停留在待填写实际转染记录的状态。
